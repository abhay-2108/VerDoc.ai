---
description: how to run VeriDoc.ai document analysis
---

To analyze a document with VeriDoc.ai, follow these steps:

1. Ensure Ollama is running items.
2. Run the following command with the path to your document:

// turbo
```powershell
.\venv\Scripts\python main.py "[path_to_your_document]"
```

Example:
```powershell
.\venv\Scripts\python main.py "Test Documents\Lease_Violation_Test.pdf"
```
